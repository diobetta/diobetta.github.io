# Portfólio GitHub Pages — Diovanna Oliveira Betta

Portfólio pessoal desenvolvido para apresentar minha trajetória, competências, certificações e projetos práticos em tecnologia.

A página reúne minha transição profissional para a área de tecnologia, conectando minha experiência anterior em operações, product marketing, dados e melhoria de processos aos estudos atuais em Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

Este portfólio foi desenvolvido como uma página estática publicada no GitHub Pages.

A proposta é apresentar, de forma objetiva e visual, projetos acadêmicos e autorais relacionados a:

* Produto e requisitos;
* Desenvolvimento web;
* UX e usabilidade;
* Dados e BI;
* Processos e operações digitais;
* Tecnologia aplicada a problemas reais.

## Bibliotecas utilizadas

A página utiliza uma estrutura simples, com dependências via CDN:

* Bootstrap, para layout, responsividade e componentes;
* Bootstrap Icons, para ícones;
* AOS, para animações suaves ao rolar a página;
* GLightbox, para visualização das imagens dos projetos;
* JavaScript próprio em `assets/js/main.js`, apenas para pequenos comportamentos da interface.

## Estrutura da página

A página está organizada nas seguintes seções:

* **Início:** apresentação principal e links rápidos;
* **Sobre:** resumo da trajetória profissional e acadêmica;
* **Competências e ferramentas:** habilidades organizadas por área;
* **Formação e trajetória:** base acadêmica e repertório profissional;
* **Projetos em destaque:** projetos acadêmicos e autorais;
* **Certificações:** formações complementares alinhadas à tecnologia, dados e métodos de trabalho;
* **Contato:** links para GitHub, LinkedIn e e-mail.

## Projetos em destaque

### Rota Digital de Agências

MVP em Python e Flask para diagnosticar o nível de maturidade digital de pequenas agências de viagens, avaliando áreas como atendimento, comercial, operação e dados.

**Tecnologias:** Python, Flask, Bootstrap e Jinja.

### Sistema de Gestão de Pacientes

Sistema em Python para simular cadastro de pacientes e registro de atendimentos em uma clínica, utilizando Programação Orientada a Objetos.

**Tecnologias:** Python, POO, terminal e Git.

### Estacionamento da DIO

Aplicação web em Flask que simula uma triagem de entrada em estacionamento, aplicando regras de negócio, condicionais e fluxo guiado.

**Tecnologias:** Python, Flask, HTML e CSS.

### Izabel Doces e Salgados

Site vitrine desenvolvido como projeto acadêmico para uma marca de doces e salgados artesanais.

**Status:** em construção.

**Tecnologias:** HTML, CSS, Bootstrap e Figma.

### Caixa de Supermercado

Simulador de caixa de supermercado em Flask, com catálogo, carrinho temporário, cálculo de desconto e pagamento simulado.

**Tecnologias:** Python, Flask, Session e Bootstrap.
